SECURITY / SANDBOX

Zero-execution isolation, by construction

No interpreter, no sandboxed shell, no eval anywhere in the pipeline. Code delivery ends at a parse — the only "run" that happens is your own.

local_verify.py PARSE-ONLY 
def verify_block(block):        # local only
    fp       = sha256(block)      # immutable reference
    tree     = ast.parse(block)   # never exec()
    issues   = scan(tree)         # syntax + scope
    fp2      = sha256(dump(tree)) # re-derive fingerprint
    assert fp == fp2            # bytes → verdict
    return verdict(fp, issues)   # ok | issues

No execution engine

Verifiers import a parser AST only. There is no compiled, interpreted, or evaluated pathway for delivered code.

Local hash-verification

Each delivered block gets a sha-256 fingerprint; the re-parsed tree must reproduce it byte-for-byte before the verdict is sealed.

Repo never ships out

Scanning touches only the working directory and writes a local summary. Sessions persist in local SQLite — the model travels, your source doesn't.

Boundaries enforced

Hash SALTED_RING + AST parse + verdict append happens inside the same process, with no subprocess spawn on the code path.
