START

Quick start

Run the local backend in three commands.

terminal — repo rootBASH
# 1. install dependencies
pip install -r requirements.txt

# 2. set the model key (see Configuration)

# 3. start the gateway (serves API + static site on :8000)
python backend/app.py

CONFIG

Configuration

All configuration is environment-driven; no secrets in code.

VariablePurpose
LLM_API_KEYPrimary provider key (OpenRouter default).
LLM_MODELDefault model for text modes.
LLM_CODE_MODELModel used by code-generation modes.
MODEL_PROVIDERRouting provider for the primary key.
HIGH_COST_SENSITIVEStricter cost cap for high-volume use.
.envEXAMPLE
LLM_API_KEY=your_key_here
LLM_MODEL=meta-llama/llama-3.3-70b-instruct
LLM_CODE_MODEL=openai/gpt-oss-120b
MODEL_PROVIDER=openrouter
API GATEWAY

API reference

POST/mentor chat + verify

Send a turn to the mentor. Empty input text is rejected with 400.

request — application/jsonBODY
{
  "session_id": "optional",
  "mode": "generate",
  "input_text": "a fib function in python",
  "language": "python"
}
response200
{
  "session_id": "a1b2c3",
  "mode": "generate",
  "language": "python",
  "result": "def fib(n): ...",
  "usage":   { "prompt_tokens", "completion_tokens", "total_tokens" },
  "model": "openai/gpt-oss-120b",
  "provider": "openrouter",
  "duration_ms": 812,
  "context":    { "note", "trimmed_turns" },

OUTPUT CONTRACT

Verification spec

Code-producing modes never execute. Output passes through a local parser before it leaves the backend, and the verdict rides along on the response.

FieldMeaning
verification.statusok when every block parsed cleanly.
verification.blocksArray of parsed code blocks, each with its own issues list.
verification.blocks[].issuesSyntax problems found by the parser — returned verbatim to you.
“Verified before shown — every time.”
